# 账号设置与自适应并发

账号编辑使用独立的 Codex 指纹、TLS 和并发配置入口。原来的“账号保护”组合开关和九种策略选择已退役，不再支持新增或切换组合策略。

## 独立配置

- Codex 指纹设置保留原有选项，包括关闭、设备、会话、完整收敛和单机多窗口。选择关闭会明确保存 `off`，不会因删除配置键而重新启用默认模式。
- TLS 配置继续使用原有入口及适用平台；指纹、TLS、代理和保存的并发上限按各自设置生效。
- 自适应并发控制来自第二上游的 `bb7cdbd2a` 提交，是独立于组合预设的功能，不会自动启用或修改身份、TLS 配置。

## 自适应并发控制

OpenAI OAuth / Setup Token 账号编辑中的“账号保护策略”已更名为“自适应并发控制”。原有存储字段 `account_protection_policy` 保留，已有配置继续读取。

打开此区域开关，勾选“自适应并发”和“自动调整”，设置最低并发后，点击底部“更新”保存。仅打开区域开关或未勾选自动调整，不会自动降低并发。

当前编辑器保存的参数为：60 秒内累计 3 次上游最终 429、5xx 或网络错误后，可将运行时并发减半（不低于所设最低值，两次调整至少间隔 10 秒）。在没有近期失败且达到恢复间隔后，成功请求促使并发逐步恢复，每次加 1，最高为账号保存的并发上限。自动调整要求账号已设置正数并发上限，不修改数据库中的该上限。

## 已启用旧版预设的账号

升级不会自动改动正在使用的身份、传输或并发设置。只有已启用旧策略的账号显示“旧版预设配置”提示和“恢复启用前配置”按钮。

- 恢复前，旧策略管理的身份／TLS 控件不可修改；普通保存仍保留旧策略配置，自适应并发可独立修改。通用并发旧策略不锁定身份／TLS。
- 点击“恢复启用前配置”并确认后，后端使用首次启用时的快照恢复受管字段。之后手动修改过的并发值会保留；自适应并发设置不受影响。
- 恢复成功后，提示消失，原有指纹和连接设置恢复独立编辑。弹窗中未保存的其他编辑继续保留。
- 还原失败或原始快照缺失时，会显示错误并保留现状，不会用猜测的默认值覆盖配置。

后端策略列表、预览和应用接口对旧客户端返回 HTTP 410；仅恢复接口保留。旧策略的运行时解析和快照还原代码仅用于兼容存量账号，不能通过这些已退役接口重新启用策略。

这些配置控制本地请求身份、连接方式和并发，不保证上游模型质量或账号安全。实际连接仍受全局 TLS、代理和插件配置影响。
