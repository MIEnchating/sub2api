# Codex 指纹收敛

本次整理以已合入的官方提交 `49a39b6dc1abed30fd227611e8af1108bc427610` 为基线。官方 Codex ticket 功能保持独立。

## 配置入口

账号管理 → 新建或编辑 OpenAI OAuth 账号 → Codex 指纹收敛。批量编辑也支持。新建账号表单默认选择单机多窗口，可手动关闭；删除了会隐式启用指纹的 `gateway.openai_account_unique_fingerprint_enabled` 全局配置。

| 模式 | 来源 | 行为 |
| --- | --- | --- |
| 关闭 | 官方 | 保留客户端身份 |
| 设备收敛 | 官方 | 只统一账号设备身份 |
| 会话收敛 | 官方 | 统一设备和会话，按客户端会话派生线程 |
| 完全收敛 | 官方 | 统一设备、会话和线程 |
| 单机多窗口 | 唯一自定义模式 | 稳定设备、三个根窗口及窗口忙时的子智能体身份；保留各会话缓存键 |

单机多窗口整合了账号稳定种子、HTTP 请求头与请求体身份一致性、WebSocket 握手身份、内置 Mac Codex TLS，以及智能测试请求的同源身份。切换账号时清理旧身份，改变 TLS 身份后不复用旧 WebSocket。窗口数只决定身份映射，**不限制请求并发**。

如果启用了另外的 OAuth 转发插件，插件仍负责自身网络传输；这里的内置 TLS 指纹仅作用于本程序直接发起的上游连接。

## 与本地账号保护兼容

Prism 实验通道随第二上游退役，删除专属 UI、运行时与凭据。迁移 `254_retire_prism_and_account_protection.sql` 在本项目只清理 Prism 配置并规范化未启用旧保护的 `account_device` 指纹别名；保留原设备种子。

本项目仍保留独立自适应并发、账号健康策略及已有旧预设的恢复入口。迁移不删除 `account_protection_policy`、旧预设快照、TLS/代理策略，不改账号并发，也不清除健康隔离或官方限流状态。旧预设由管理员通过“恢复启用前配置”退役，不能新建旧预设。

已有显式单机模式继续生效；存量未配置模式的账号仍按官方默认关闭；新建账号表单默认写入单机多窗口。普通账号多代理、Codex ticket 和账号生成预览保持独立。

## 验证范围

指纹测试覆盖身份稳定、HTTP/WS 和账号测试的一致性、TLS 切换后的连接复用，以及并发不被指纹模式改写。迁移测试覆盖 Prism 清理、精确种子、旧保护和自适应配置保留及重复执行；需要 PostgreSQL 集成验证环境。
